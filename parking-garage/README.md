# Smart Parking Garage

A parking garage wants software to manage vehicle entry and exit.

The business has provided the following requirements.

## Requirements

The garage has a fixed capacity.

Vehicles can enter.

Vehicles can leave.

The system should know:

* How many spaces are occupied.
* How many spaces remain available.

Business rules:

* A vehicle cannot enter when the garage is full.
* A vehicle cannot leave if it is not currently parked.
* The occupancy count must always be accurate.

## Additional Requirements

Once the core functionality is working, consider:

* Different vehicle types.
* Reserved spaces.
* Parking charges.
* Peak occupancy reporting.

## Acceptance Criteria

The behaviour should be proven through automated tests.

The implementation details are entirely your choice.
